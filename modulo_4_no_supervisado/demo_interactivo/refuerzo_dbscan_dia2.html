💥 1. El Problema: K-Means se Rompe con Datos Corruptos

Mira qué pasa cuando hay UN solo dato corrupto en tu dataset de 50 pozos. K-Means lo fuerza a un cluster y DISTORSIONA todo.

K=3 · El punto rojo brillante (sensor dañado: Qo=99,999 bpd) JALA el centroide del Cluster 2. DBSCAN lo aísla.
⚠️ Un solo sensor dañado contamina a todos los pozos sanos. K-Means no tiene forma de decir "este punto no pertenece". DBSCAN sí.

🧩 2. DBSCAN: Agrupando por Densidad, No por Distancia a un Centro

DBSCAN hace DOS preguntas por cada punto:

🔍 Pregunta 1

"¿Cuántos vecinos tengo en un radio ε (epsilon)?"

Si tengo ≥ MinPts vecinos → soy CORE POINT.

🔍 Pregunta 2

"Si no soy core... ¿estoy cerca de alguien que SÍ lo es?"

Si sí → BORDER POINT. Si no → RUIDO (-1).

📐 Analogía del estacionamiento: ε = distancia que caminas para considerar 2 autos "juntos". MinPts = cuántos autos necesitas para decir "esto es un grupo". Un auto SOLO a 50m → RUIDO.

🎛️ 4. Calibrando Epsilon (ε) — El Gráfico K-Distance

ε NO se adivina. Para cada punto medimos la distancia a su 4to vecino, ordenamos, y buscamos EL CODO.

Mueve el cursor sobre la curva. El codo en ~0.25 es donde la pendiente cambia — puntos antes = densos, después = ruido.
⚠️ Regla: ε antes del codo → casi todo ruido. ε después → todo un solo cluster. El codo es el balance.

⚔️ 5. ¿Cuándo usar K-Means y cuándo DBSCAN? — 2 Escenarios

No hay un algoritmo "mejor". Depende de tus DATOS. Aquí tienes dos escenarios opuestos:

🔵 Escenario A: Datos LIMPIOS y ESFÉRICOS

Gana K-Means. Rápido, simple, clusters compactos.

🟡 Escenario B: Datos con RUIDO y FORMAS IRREGULARES

Gana DBSCAN. Aísla outliers, encuentra formas reales.

📋 Guía Rápida de Decisión

PreguntaSi la respuesta es SÍSi la respuesta es NO
¿Mis datos tienen outliers o sensores dañados?→ DBSCAN→ K-Means
¿Sé exactamente cuántos grupos hay?→ K-Means→ DBSCAN
¿Mis clusters tienen formas raras (no esféricas)?→ DBSCAN→ K-Means
¿Necesito velocidad con muchos datos?→ K-Means→ DBSCAN
¿Quiero detectar automáticamente datos corruptos?→ DBSCAN→ K-Means
💡 Regla práctica petrolera: ¿Datos de 50 pozos limpios? K-Means. ¿Telemetría SCADA con interferencia? DBSCAN. ¿Well logs para litofacies? K-Means sobre PCA (Día 3).

💻 6. El Pipeline DBSCAN Completo

# PASO 1: Escalar (¡IGUAL que K-Means!) from sklearn.preprocessing import StandardScaler scaler = StandardScaler() X_scaled = scaler.fit_transform(df[['Qo_bpd','WHP_psi']]) # PASO 2: Calibrar ε (el "Yellowbrick" de DBSCAN) from sklearn.neighbors import NearestNeighbors neigh = NearestNeighbors(n_neighbors=4).fit(X_scaled) dists = np.sort(neigh.kneighbors(X_scaled)[0][:,3]) plt.plot(dists) # ← Buscar el CODO → ε ≈ 0.25 # PASO 3: Entrenar DBSCAN from sklearn.cluster import DBSCAN db = DBSCAN(eps=0.25, min_samples=4) df['Cluster'] = db.fit_predict(X_scaled) # -1 = RUIDO = ¡ANOMALÍA DETECTADA!
🔑 3 líneas de código. La verdadera habilidad no es escribir más — es calibrar ε correctamente con el k-distance graph.
